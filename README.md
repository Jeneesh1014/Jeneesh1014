## 🔭 What I'm Building Right Now

### 🛡️ [Safe MCP Agent](https://github.com/Jeneesh1014/safe-mcp-agent) — *actively in progress*

A local, zero-API-cost agent that connects to enterprise-style tools through MCP — protected by a custom 5-layer guardrail middleware, and measured by a from-scratch evaluation harness (`mcp-guardeval`) that scores real attack techniques against the SAFE-MCP framework.

**Agent · Shield · Ruler** — an agent that acts, a security layer that checks every tool call before it runs, and a harness that proves the shield actually works. It requests human approval before any destructive action and shows a real-time diff preview before executing.

`LangGraph` `MCP` `Ollama` `Pydantic` `OpenTelemetry` `Pytest`
**Highlight:** 100% of tested destructive actions blocked · real-time diff preview · built to MCP v1.0
